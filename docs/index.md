# Документация оператора стенда

Руководство описывает интерфейс, телеметрию и основные термины стенда тестирования беспилотных авиационных систем.

Документация предназначена для операторов, которые работают со стендом, контролируют выполнение испытаний и анализируют угловую телеметрию в реальном времени.

## Назначение стенда

Стенд используется для моделирования внешних воздействий на беспилотную авиационную систему.

В рамках операторской документации рассматриваются:

- работа внутреннего и внешнего колец;
- отображение параметров на графике телеметрии;
- связь осей стенда с авиационными терминами;
- интерпретация линий графика;
- ограничения кинематики стенда.

## Что отображается на графике

В окне телеметрии отображаются две линии:

### Линия оси Y

Отображает положение внутреннего кольца.

Связана с [тангажом](operator/glossary/pitch.md) и имитацией силы ветра по [шкале Бофорта](operator/glossary/beaufort-scale.md).

### Линия оси Z

Отображает положение внешнего кольца.

Связана с [направлением](operator/glossary/heading.md) и ориентацией стенда относительно заданной стороны света.

Параметр [угла атаки](operator/glossary/angle-of-attack.md) отдельной линией не отображается.

## Ограничения стенда

Стенд не реализует отдельную ось крена.

Поэтому крен:

- не управляется как независимый параметр;
- не отображается отдельной линией телеметрии;
- не используется как основной термин в операторской документации.

Для описания внешнего кольца используется термин [направление](operator/glossary/heading.md), а не крен.
