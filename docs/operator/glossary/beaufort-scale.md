# Шкала Бофорта

## Назначение

Шкала Бофорта используется для задания силы ветра при моделировании внешнего воздействия на стенде.

На стенде значение по шкале Бофорта связано с изменением [тангажа](pitch.md) через [ось Y](axis-y.md).

## Использование на стенде

Чем выше значение шкалы Бофорта, тем сильнее имитируемая ветровая нагрузка.

В интерфейсе изменение этого параметра отображается через линию тангажа.
