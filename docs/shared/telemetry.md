# Телеметрия стенда

## Назначение

Телеметрия используется для отображения текущего состояния стенда в режиме реального времени.

---

## Источники данных

Телеметрия формируется на основе данных приводов:

- внутреннего кольца;
- внешнего кольца.

Подробнее о конструкции стенда см. [Кинематика стенда](stand-kinematics.md).

---

## Визуализация

Телеметрия отображается в виде непрерывного графика.

Принцип отображения аналогичен самописцу или электрокардиографу.

По горизонтальной оси отображается время.

По вертикальной оси отображаются значения параметров.

Элементы интерфейса описаны в разделе [Термины пользовательского интерфейса](../operator/glossary/ui.md).

---

## Отображаемые линии

### Линия оси Y

Отображает:

- положение внутреннего кольца;
- [тангаж](../operator/glossary/pitch.md).

Связанные материалы:

- [Ось Y](../operator/glossary/axis-y.md)
- [Тангаж](../operator/glossary/pitch.md)

---

### Линия оси Z

Отображает:

- положение внешнего кольца;
- [направление (курс)](../operator/glossary/heading.md).

Связанные материалы:

- [Ось Z](../operator/glossary/axis-z.md)
- [Направление](../operator/glossary/heading.md)

---

## Ограничения отображения

Телеметрия отображает только параметры, непосредственно связанные с приводами стенда.

Параметр [угла атаки](../operator/glossary/angle-of-attack.md) отдельной линией не отображается.

Параметр [рыскания](../operator/glossary/yaw.md) отдельной линией не отображается.

---

## Назначение оператора

По телеметрии оператор контролирует:

- выполнение программы испытаний;
- изменение параметров воздействия;
- корректность работы приводов;
- наличие отклонений от заданного сценария.
